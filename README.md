Business Intelligence (BI) Project - Pizza Sales Report 

Problem Statement:
Addressed reporting and sales performance analysis challenges for a pizza chain by implementing an end-to-end BI solution.

Objective:
Design and implement a Power BI reporting solution to centralize pizza sales data, clean and model the data, and develop interactive dashboards for sales insights, customer trends, and performance tracking.

Responsibilities:
Led the BI project lifecycle, utilizing Power Query for data cleansing, transformation, and modeling in Power BI.
Developed calculated columns and measures using DAX to support key business metrics and built insightful visual reports to track sales performance, trends, and customer demographics.

Achievements:
Successfully imported and integrated pizza sales data from a MySQL database into Power BI.
Applied Power Query for data cleansing and transformation to ensure data quality and consistency.
Created DAX measures to enable detailed sales trend analysis, customer segmentation, and product performance insights.
Built comprehensive and visually engaging dashboards to support strategic decisions for marketing and sales teams.
Enabled real-time data access, facilitating faster and more informed decision-making.

Outcome:
Enhanced data visibility and business intelligence, enabling the team to identify top-selling products, peak sales times, and key customer segments, ultimately improving sales strategies and operational efficiency.
